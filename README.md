# Calculator + MySQL

## خطوات التشغيل

1. **جهّز قاعدة البيانات**
   - افتح MySQL وشغّل محتوى ملف `schema.sql` (بيعمل الداتابيز والجدول).

2. **عدّل بيانات الاتصال**
   - في `server.js` غيّر `password` (وأي بيانات لازمة) في `dbConfig` بما يطابق سيرفر MySQL بتاعك.

3. **نصّب المكتبات**
   ```
   npm install
   ```

4. **شغّل السيرفر**
   ```
   npm start
   ```

5. **افتح المتصفح على**
   ```
   http://localhost:3000
   ```

## ملاحظات
- مفيش أي نظام تسجيل دخول أو صلاحيات — الشغل مباشر زي ما طلبت (بدون security).
- كل عملية حسابية (+ - × ÷) بتتسجل تلقائي في جدول `calculations` بالتاريخ والوقت.
- تقدر تشوف السجل كامل تحت الحاسبة، وتحذف أي عملية منه.
- لو عايز تضيف حماية بعدين (تسجيل دخول، JWT، إلخ) قولّي وهنضيفها فوق النظام ده بسهولة.
